# RabbitMQ PDM → Worker → ERP

Репозиторий содержит материалы по интеграции 1С PDM → RabbitMQ → .NET Worker → 1С ERP.

## Важно

Содержимое каталога `source-snapshots` — снимки исходных модулей для ревизии, не готовые production-патчи. Перед внедрением нужно реализовать и проверить:

- обработку `kindSourceRef` и `kindName` в ERP;
- установку обязательного `ВидНоменклатуры`;
- устойчивое сопоставление UUID источника PDM с ссылкой ERP;
- публикацию событий PDM после успешной записи с outbox/повтором;
- подтверждение RabbitMQ только после успешной обработки в ERP.

Не коммитьте пароли, токены и другие секреты. Используйте защищённую конфигурацию и TLS в production.

Документы контракта и настройки RabbitMQ будут размещены в корне репозитория.
