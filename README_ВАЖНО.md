Содержимое:
- `PDM_СозданиеНоменклатурыСервер_исходный_полный.bsl` — полный исходный модуль из архива PDM, без изменений.
- `PDM_ИнтеграцияCADHTTP_исходный_полный.bsl` — полный исходный модуль HTTP-обработчика PDM, без изменений.
- `PDM_HTTPService_исходный_полный.bsl` — полный исходный модуль HTTP-сервиса PDM, без изменений.
- `ERP_ИнтеграцияRabbitMQСервер_исходный_полный.bsl` — полный исходный модуль ERP, без изменений.
- `ERP_HTTPService_СоздатьИзделие_полный.bsl` — полный исходный модуль HTTP-сервиса ERP, без изменений.
- `JSON_контракт_PDM_RabbitMQ_Worker_ERP.md` — версия 1 контракта сообщений.
- `RabbitMQ_настройки_system_integration.md` — топология, права и безопасная обработка.

## Статус

Это комплект исходников и согласованного контракта, а не готовый к загрузке production-патч. В BSL-модулях ERP необходима реализация обработки `kindSourceRef`/`kindName`, обязательного `ВидНоменклатуры` и устойчивого сопоставления UUID источника с ERP-ссылкой. Сейчас эти части отсутствуют в фактическом исходнике ERP, поэтому не подменены предположениями. В PDM нужно добавить публикацию событий только после успешной записи и обработку ошибок публикации через outbox/повтор, иначе ошибка RabbitMQ может возникнуть после записи в PDM и событие потеряется.

Не загружать файлы `*_исходный_полный.bsl` поверх модулей: это снимки исходного состояния для ревизии.
